# Brijesh M Portfolio

React + Vite portfolio,
focused on AI document intelligence, OCR, LLM integration, vision-language models, backend architecture, and applied AI projects.

## Run Locally

Install Node.js first if it is not available on your system.

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```

The production files will be generated in `dist/`.
